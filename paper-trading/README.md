# ペーパートレード管理

仮想資金による日本株のペーパートレード(模擬売買)を記録・管理するディレクトリ。

## 前提

- 初期資金: **1,000万円**(仮想)
- 約定は基本的に**終値ベース**、手数料・税金は考慮しない
- 売買単位は100株(単元株)を基本とする

## ファイル構成

| ファイル | 内容 |
|---|---|
| `portfolio.json` | 現在の保有状況(現金・ポジション・時価) |
| `trades.csv` | 全売買履歴 |
| `scripts/paper_trade.py` | 管理CLI(Python3標準ライブラリのみ) |

## 使い方

```bash
cd paper-trading

# 損益レポート
python3 scripts/paper_trade.py report

# 買付 (コード 株数 価格)
python3 scripts/paper_trade.py buy 7974 100 7300
python3 scripts/paper_trade.py buy 6758 100 3500 --name ソニーG   # 新規銘柄は表示名を指定

# 売却
python3 scripts/paper_trade.py sell 7974 100 7500

# 時価の更新(評価損益の計算に使用)
python3 scripts/paper_trade.py price 7974 7350

# 追加入金
python3 scripts/paper_trade.py deposit 1000000
```

日付を指定する場合は `-d 2026-07-21`、メモは `-n "決算前に利確"` のように付ける。

## 米国株の扱い

米国株は**円換算した1株単価**(約定日のUSD終値×ドル円終値)で記録する。取引メモにUSD価格と為替レートを残す。評価損益には株価変動と為替変動の両方が含まれる。
