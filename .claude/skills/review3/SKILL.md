# /review3 — 3観点レビュー

## 目的
ノートを3つの観点で厳しく点検し、判断の質を上げる。

## 3観点
1. **事実（Fact）**: 主張の根拠は? 出典は確かか? 憶測と事実が分離されているか。
2. **示唆（Implication）**: だから何? 次アクションに繋がるか。過大/過小評価は。
3. **反証（Counter）**: この結論が間違うとしたら? 反対の証拠・別解釈は。

## 手順
1. 対象ノートを読む。
2. 3観点それぞれで指摘を箇条書き（各観点 最低1件、無ければ「なし」と根拠）。
3. `40_reviews/YYYYMMDD-<slug>-review3.md` を作成（`type: weekly` ではなく専用に `type: note`, `status: processed`、本文冒頭に対象ノート id を明記）。
4. 重大な反証があれば元ノートへ「要再判断」を追記案として提示（編集は承認後）。

## 完了報告
3観点の指摘件数と、最も重要な反証を1つ要約。
