# 会員コミュニケーションマニュアル（WESTER CS エージェント向け）

> **このマニュアルの目的**
> WESTER会員へのあらゆるコミュニケーション（メール・プッシュ通知・バナー・SMS）において、一貫した品質・トーン・正確性を保つための実務標準を定める。このマニュアルを参照することで、経験を問わず誰でも同水準の会員向けコミュニケーションを作成できる。

---

## 1. WESTER会員の理解（属性・利用目的・期待値・感情）

### 1-1. WESTER会員の主要属性

WESTER会員は一様ではなく、多様な属性を持つ利用者から構成されている。コミュニケーションを設計する前に、誰に向けて何を伝えるかを明確にする必要がある。

**年齢層別分布（概算）：**
| 年齢層 | 比率 | 特徴 |
|--------|------|------|
| 10〜20代 | 約20% | スマートフォンネイティブ・SNS感度高・鉄道より他の移動手段も使う |
| 30〜40代 | 約35% | 通勤・出張が中心・時間効率を重視・ポイント活用に積極的 |
| 50〜60代 | 約30% | 観光・趣味旅行が中心・信頼性・わかりやすさを重視 |
| 70代以上 | 約15% | アプリ操作に不安がある場合もある・丁寧な説明が必要 |

**利用目的別分類：**

| タイプ | 主な利用目的 | コミュニケーションで押すべき訴求点 |
|--------|------------|--------------------------------|
| 通勤・通学利用者 | 定期的な日常移動 | 時間短縮・確実な到着・ポイント蓄積 |
| 旅行・観光利用者 | レジャー・週末旅行 | お得な旅行パック・スタンプラリー・季節キャンペーン |
| 出張利用者 | ビジネス移動 | 経費精算連携・グリーン車特典・時間帯の確実性 |
| ショッピング利用者 | ポイント目的 | ポイント付与率・交換先の豊富さ・有効期限 |

### 1-2. 会員が期待すること

| 期待の種類 | 具体的な内容 |
|-----------|------------|
| 正確な情報 | 誤りのない金額・日程・条件の記載。一度でも誤情報を受け取ると信頼が損なわれる |
| タイムリーな情報 | キャンペーン情報は「間に合う」タイミングで受け取りたい。終了直前の通知では利用できない |
| 自分に関係ある情報 | 使わない路線・関係ないサービスの通知が続くと「迷惑メール」と判断される |
| 簡潔さ | 長文・複雑な条件の案内は読まれない。要点を3秒で把握できる構成を求めている |
| 丁寧・誠実な対応 | 問題発生時に隠蔽・遅延対応があると、SNSで拡散されるリスクが高い |

### 1-3. 会員のネガティブな感情が生まれる場面

以下の場面では会員が強いネガティブ感情（不満・怒り・不安）を持ちやすい。これらの場面では通常より高い配慮が必要。

1. **ポイント有効期限切れ通知：** 「なぜもっと早く知らせなかったのか」という怒り
2. **キャンペーン条件の変更・終了：** 「途中で変えるのは詐欺だ」という不信感
3. **システム障害・メンテナンス：** 「信頼できないサービス」という失望
4. **個人情報関連の通知：** 「自分の情報が漏れたのか」という強い不安
5. **誤送信・誤案内：** 「きちんとしていないサービス」という信頼喪失
6. **遅延・運休に関する案内：** 「なぜもっと早く言わなかったのか」という苛立ち

## 2. 会員コミュニケーションの5原則

### 原則1：正確性（Accuracy）

会員に伝える情報は、発信前に必ず以下を確認する。

- **日付・時刻：** 開始日・終了日・メンテナンス時間帯に誤りがないか
- **金額・ポイント数：** 付与ポイント・割引額・対象金額に誤りがないか
- **条件・対象：** 誰が対象か・どの路線・サービスが対象かに誤りがないか
- **リンク先URL：** 誘導先のURLが正しく動作しているか
- **法的表記：** 景品表示法・個人情報保護法上必要な記載が含まれているか

**誤情報を送信した場合のリスク：** 会員への謝罪対応・CS問い合わせの急増・ブランドイメージの毀損。1件の誤情報送信が数千件の問い合わせを生むことがある。

### 原則2：簡潔性（Brevity）

会員は1通のメール・通知に長時間をかけない。

- **メール：** 本文は最大400字以内を目安とする（詳細は「詳細はこちら」でリンク先に誘導）
- **プッシュ通知：** 最大140字（件名+本文）に収める
- **一文の長さ：** 読点を使っても1文60字以内
- **箇条書き優先：** 3点以上の情報は箇条書きにする

### 原則3：適切性（Relevance）

不必要な通知を送り続けると、会員はアプリの通知をオフにするか退会する。

- **セグメント配信を徹底する：** 関東エリア利用者に「大阪環状線キャンペーン」を送らない
- **利用頻度・利用路線でターゲティングする：** 過去6ヶ月の乗車実績を基にセグメントを設定する
- **配信頻度は週2回以内を目安とする：** 施策が重複する場合は配信を統合・調整する

### 原則4：誠実性（Integrity）

JR西日本グループの公共インフラとしての信頼を維持するために、誇張・誤解を招く表現・不必要な煽り文句を使わない。

- 「今すぐ！」「絶対お得！」「見逃したら損！」等の扇情的な表現は最小限にする
- キャンペーン条件は正確かつ完全に記載する（見かけ上の条件と実際の条件の乖離を作らない）
- 問題が発生した場合は隠蔽せず、誠実に事実を伝える

### 原則5：一貫性（Consistency）

会員に送るすべてのコミュニケーションで、WESTERブランドとして一貫したトーン・表記を保つ。

- 表記の統一：「ポイント」と「pt」を混在させない（→ 「ポイント（pt）」の形で初出時に定義し、以降は「pt」統一でも可）
- 文体の統一：同一チャネルでは丁寧語（です・ます調）に統一する
- ブランド名の表記：「WESTER」「WESTERポータル」「WESTER会員」の表記を定義通りに使う
- 担当者によって文体・トーンがバラバラにならないよう、送信前に本マニュアルのテンプレートと照合する

## 3. チャネル別ガイドライン（メール・プッシュ通知・ポータルバナー・SMS）

### 3-1. メール

**適用場面：**
- キャンペーン告知（詳細説明が必要なもの）
- ポイント付与・失効の通知
- 重要なサービス変更案内
- 利用明細・月次レポート
- 規約・ポリシーの変更通知

**メールの仕様基準：**

| 項目 | 基準 |
|------|------|
| 件名 | 32字以内（スマートフォンでの表示を考慮）。キーワード（ポイント・キャンペーン等）を前半に配置 |
| 差出人名 | 「WESTERポータル」（個人名・担当者名は使わない） |
| 本文 | 最大400字目安（詳細はリンク先） |
| フォント | 明朝体・ゴシック体どちらも可。ただし1通で混在させない |
| リンク | CTAボタン（「詳しくはこちら」等）を本文後半に1〜2個配置 |
| 配信停止 | 全メールの末尾に「配信停止はこちら」リンクを必須記載（特定電子メール法） |
| HTML/テキスト | HTMLメール推奨（テキストのみのフォールバックも必須設定） |

**送信タイミングの目安：**

| 種類 | 推奨送信時間帯 | 理由 |
|------|-------------|------|
| キャンペーン告知 | 火〜木の10時または18時 | メール開封率が最も高い時間帯 |
| ポイント失効通知 | 失効30日前・7日前・当日 | 余裕をもって行動できるタイミング |
| 重要なお知らせ | 事象発生後できるだけ早く（遅くとも当日中） | 速報性が信頼性に直結 |
| メンテナンス案内 | メンテナンス開始72時間前・24時間前 | 利用者が代替手段を準備できる時間 |

---

### 3-2. プッシュ通知

**適用場面：**
- 時間限定・期間限定の告知（緊急性の高いもの）
- 個人の行動に連動した通知（乗車後のポイント付与確認・スタンプ取得）
- リマインド（施策終了間際の参加促進）
- 重要なシステム障害・運行情報

**プッシュ通知の仕様基準：**

| 項目 | 基準 |
|------|------|
| 件名（タイトル） | 最大25字（iOSの表示上限） |
| 本文 | 最大115字（件名と合わせて140字以内） |
| 送信頻度 | 1日1通まで（緊急の運行情報を除く）。施策重複時は優先度を判断して統合 |
| 送信時間 | 7時〜21時の間（深夜・早朝は原則禁止） |
| ディープリンク | 通知タップ時に関連ページ（キャンペーン詳細・マイページ等）に直接遷移させる |
| パーソナライズ | 可能な限り会員名・乗車路線を含める（「○○様、今週も●●線をご利用ありがとうございます」） |

**プッシュ通知の構成：**
```
[件名：最大25字]（例：「夏のスタンプラリー開始！」）
[本文：最大115字]（例：「本日より関西50駅スタンプラリーがスタート。全駅コンプリートで1,000pt獲得！8/31まで。アプリを開いて参加登録する」）
```

**プッシュ通知の禁止事項：**
- 同一内容を同日に2回以上配信する
- 21時〜翌7時の配信（緊急の安全情報を除く）
- 会員が許可していないカテゴリの通知を送る

---

### 3-3. ポータルバナー（WESTERアプリ内トップページ）

**適用場面：**
- 現在実施中のキャンペーン告知
- 新機能・サービス追加の案内
- 季節の挨拶・情報（年末年始・ゴールデンウィーク等）

**バナーの仕様基準：**

| 項目 | 基準 |
|------|------|
| キャッチコピー | 最大20字（視認性重視） |
| サブテキスト | 最大40字（詳細情報） |
| 画像サイズ | デザイン担当者に確認（横長バナー・正方形バナーの2パターン） |
| 掲載期間 | 施策期間中のみ（終了日の翌日には必ず掲載を終了する） |
| リンク先 | 必ず施策の詳細ページまたは参加登録ページに遷移させる |
| バナー数 | 同時掲載は最大3枚（それ以上はカルーセル表示で対応） |

**バナーコピーの書き方：**
- 数字を使う：「最大1,000pt獲得」「50駅制覇」（具体的な数字は注目を引く）
- 期限を示す：「8/31まで」（緊急性を演出する）
- 行動を促す：「今すぐ参加」「詳しくはこちら」（曖昧な表現は避ける）

### 3-4. SMS

**適用場面：**
- 最重要かつ確実に届けたい案内（個人情報漏洩通知・重大な不具合に関するお詫び等）
- メールが届かないことが判明した場合の補完
- 二段階認証・本人確認コードの送信

**SMSの仕様基準：**

| 項目 | 基準 |
|------|------|
| 文字数 | 最大670字（全角）ただし実務上は200字以内に収める |
| 送信元名 | 「WESTER」または「JR西日本WESTER」（短縮URLを使う場合は信頼できるドメインのみ） |
| リンク | 短縮URLを使う場合は信頼性の高いサービスのみ使用。フィッシング対策のため正規URLの表示を推奨 |
| 使用頻度 | 最低限（重要案件のみ）。日常的なキャンペーン告知にSMSを使わない |
| 配信時間 | 8時〜20時の間に限定 |

## 6. 敬語・丁寧語の使い方（鉄道事業者としての言葉遣い）

### 6-1. 基本文体の設定

WESTERのすべての会員向けコミュニケーションは「丁寧語（です・ます調）」を基本とする。

**禁止する文体：**
- 命令形：「今すぐ登録せよ」「利用しろ」
- タメ口・フレンドリーすぎる口語：「めっちゃお得！」「やばいキャンペーン」
- 過度に馴れ馴れしい表現：「ねえ○○さん、知ってる？」

**推奨する文体：**
- 「ご利用いただきありがとうございます」（感謝）
- 「〜ご確認ください」（依頼）
- 「ご不便をおかけしますことをお詫び申し上げます」（謝罪）
- 「〜をお願い申し上げます」（丁寧な依頼）

### 6-2. 敬語の正しい使い方一覧

| 場面 | NG表現 | OK表現 |
|------|--------|--------|
| 感謝 | 「ありがとう」 | 「ありがとうございます」 |
| 高度な感謝 | 「ありがとうございます」 | 「誠にありがとうございます」「厚く御礼申し上げます」 |
| お願い | 「〜してください」 | 「〜していただけますと幸いです」「〜くださいますようお願い申し上げます」 |
| 謝罪（軽微） | 「すみません」 | 「ご不便をおかけして申し訳ございません」 |
| 謝罪（重大） | 「申し訳ありません」 | 「誠に申し訳なく、深くお詫び申し上げます」 |
| 確認依頼 | 「確認して」 | 「ご確認いただきますようお願いいたします」 |
| 利用促進 | 「使ってください」 | 「ぜひご活用ください」「ご利用をお待ちしております」 |
| 問合せ誘導 | 「問い合わせてください」 | 「ご不明な点はお気軽にお問い合わせください」 |

### 6-3. JR西日本・WESTER固有の表記ルール

| 項目 | 正しい表記 | 誤った表記 |
|------|-----------|----------|

## 8. センシティブな話題の扱い方（遅延・事故・個人情報等）

### 8-1. 運行遅延・運休に関する案内

**基本原則：**
- 事実を正確に・速やかに伝える（憶測・不確かな情報は含めない）
- 謝罪は簡潔に（過度な謝罪文は本質的な情報を薄める）
- 代替手段の情報を含める（可能な場合）

**NG表現：**
- 「多数のお客様にご不便をおかけしていることを誠に遺憾に思います」（遺憾＝残念に思う、という意味で謝罪にならない）
- 「一部列車に遅れが生じています」（曖昧。路線・区間を特定する）
- 「安全を最優先に運行しています」（遅延の理由・復旧見込みを書かない回避的表現）

**OK例：**
```
【プッシュ通知】
JR神戸線 現在遅延中（尼崎〜三ノ宮間）

車両点検のため、JR神戸線（尼崎〜三ノ宮間）で列車が遅延しています。現在の遅延：約25分。復旧目途は18:30頃の予定です。
```

**最重要原則：** 個人情報に関するコミュニケーションは、法務部門・情報セキュリティ部門の確認を必ず経る。担当者単独での文章確定は禁止。

## 9. A/Bテスト用コピー作成の方法

### 9-1. A/Bテストの目的と対象

A/Bテストは、2種類の異なるコピー（件名・本文・CTA等）を会員グループに分けて送信し、どちらがより高い効果（開封率・クリック率・コンバージョン）を生むかを検証する手法である。

**A/Bテストで検証できる要素：**

| 要素 | 検証例 |
|------|-------|
| メール件名 | 数字訴求型 vs 感情訴求型 |
| プッシュ通知の書き出し | 期限訴求型 vs 特典訴求型 |
| CTAボタンのテキスト | 「今すぐ参加」vs「詳しくはこちら」 |
| パーソナライズ | 会員名あり vs 会員名なし |
| 配信時間帯 | 朝10時 vs 夕方18時 |

### 9-2. A/Bテストの設計手順

**STEP 1：仮説を立てる**
「〜すれば〜の効果が出るはず」という仮説を立ててからテストを設計する。仮説のないA/Bテストは結果の解釈ができない。

例：「件名に具体的な数字（ポイント数）を入れると、入れない場合より開封率が高くなるはずだ。なぜなら、数字はスキャン時に目に入りやすいから」

**STEP 2：変数は1つだけ変える**
件名を変える場合は本文を同一にする。件名と本文を同時に変えると、どちらの効果かわからなくなる。

**STEP 3：サンプルサイズを決める**
統計的に有意な結果を得るために、A群・B群それぞれ最低2,000通以上の配信を行う。

**STEP 4：結果を測定する**
- 開封率（メール・プッシュ通知）
- クリック率（メール・バナー）
- コンバージョン率（参加登録・ポイント利用等）

**STEP 5：次の施策に活かす**
勝利したバージョン（効果の高かったほう）を次回施策のデフォルトにする。

### 9-3. A/Bテスト用コピーセット例（メール件名）

```
【テスト対象】メール件名
【仮説】数字を前半に配置すると開封率が上がる

Pattern A（数字前半型）：
「【WESTER】1,000pt獲得のチャンス！夏のスタンプラリー開催中」

Pattern B（感情訴求型）：
「【WESTER】今年の夏は、駅めぐりでポイントを貯めよう」

Pattern C（期限訴求型）：
「【WESTER】8/31まで限定！スタンプラリーで最大1,000pt」

【測定指標】開封率・クリック率
【配信規模】各パターン5万通（計15万通）
【結果判断基準】開封率の差が1%以上かつ統計的有意水準p<0.05
```

## 10. NG表現と代替表現一覧（最低15件）

### 会員への配慮不足・誤解招くNG表現

| # | NG表現 | 問題の理由 | 代替表現 |
|---|--------|-----------|---------|
| 1 | 「ご了承ください」 | 会員に一方的な受け入れを強制する。謝罪や説明の代わりに使うと誠実さが失われる | 「ご不便をおかけしますことを深くお詫び申し上げます」または「何卒ご理解くださいますようお願い申し上げます」 |
| 2 | 「〜となっております」 | 責任の所在が曖昧になる逃げ表現。「なっている」のは誰かが決めたはず | 「〜です」「〜とさせていただきます」 |
| 3 | 「ご迷惑をおかけして誠に遺憾です」 | 「遺憾」は「残念に思う」という意味であり謝罪の言葉ではない | 「ご迷惑をおかけして誠に申し訳ございません」 |
| 4 | 「一部のお客様に影響が出ています」 | 「一部」は責任を小さく見せるための表現と受け取られることがある。影響範囲を明確に | 「[路線名/サービス名]をご利用の会員の皆様にご不便をおかけしています」 |
| 5 | 「近日中に対応いたします」 | 「近日中」は期限が不明。会員は「いつ？」と不安になる | 「〇月〇日（〇）までに対応いたします」または「現在対応中です。〇日以内にご連絡します」 |
| 6 | 「予告なく変更することがあります」 | 規約上は許容されても、会員信頼を損なう可能性がある。変更する場合は事前通知が望ましい | 「変更の際は事前にアプリ内またはメールにてお知らせします」 |
| 7 | 「以上、ご確認よろしくお願いします」 | 「よろしく」は口語的・曖昧。何を確認してほしいか不明 | 「ご不明な点がございましたら、アプリ内の「ヘルプ」よりお問い合わせください」 |
| 8 | 「お客様各位」 | 「各位」は複数の組織・グループへの敬称。個人会員に使うと冷たく感じられる | 「WESTER会員の皆様」または個別に「○○様」 |
| 9 | 「何卒ご了承の程よろしくお願い申し上げます」 | 二重の依頼形（「よろしくお願い申し上げます」と「ご了承」）で意味が重複する | 「何卒ご理解いただきますようお願い申し上げます」 |
| 10 | 「ご不便をおかけして申し訳ございません」の後に「詳細は〜」とだけ書く | 謝罪の後に誘導だけでは誠意が伝わらない。具体的な改善・補償内容を続ける | 「ご不便をおかけして申し訳ございません。〇〇については〇〇で対応しております。〇〇様の[ポイント/乗車履歴等]には影響がないことを確認しております」 |
| 11 | 「この機会にぜひ！」 | 過度に軽い煽り文。重要なお知らせに使うと文脈が崩れる | キャンペーン告知のみに使用し、重要なお知らせ・お詫びには使わない |
| 12 | 「実は〜」「じつは〜」 | 口語的すぎる書き出し。会員向けコミュニケーションには不適切 | 「ご存知でしょうか」「新たにご案内できる機能があります」 |
| 13 | 「お得情報満載！」 | 「満載」は主観的な強調表現。何がお得かを具体的に書く | 「今月は〇〇ptアップキャンペーン、〇〇割引、〇〇特典の3つのお知らせがあります」 |
| 14 | 「〜してしまいました」 | 「してしまった」は話し言葉。正式な文書では不適切 | 「〜いたしました」「〜が発生しました」 |
| 15 | 「ご不明の点はご連絡ください」 | 「ご連絡ください」は会員にアクションを求める表現だが、「どこへ」「どうやって」が不明 | 「ご不明な点はアプリ内の「ヘルプ・お問い合わせ」よりお問い合わせください（対応時間：平日9:00〜18:00）」 |
| 16 | 「この度は誠に申し訳ございませんでした」（問題が解決していない段階で過去形を使う） | 過去形は問題が完全に解決した後に使う。解決前に使うと、まだ問題が続いているのに謝罪が完了しているように見える | 「現在、〇〇の問題が発生しており、解決に向けて取り組んでおります。ご迷惑をおかけして申し訳ございません」 |
| 17 | 「当然ながら」「言うまでもなく」 | 会員を下に見ているような印象を与える | 削除するか、「〇〇については〇〇のようになっています」と事実を説明する |
| 18 | 「最後に一言」 | メール・通知においてこのような前置きは不要 | 前置きなしに内容を書く |
