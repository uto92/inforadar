## WESTERエージェントシステム 全エージェント共通 ブランドコミュニケーション規範

**文書種別**: スキルマニュアル（新入担当者研修用）

**最終更新**: 2026年3月
**管理責任**: WESTERブランド管理チーム

## はじめに

本マニュアルは、WESTERブランドに関わるすべてのコミュニケーションを一定の品質・統一感で実施するために作成されました。エージェント・担当者を問わず、WESTERに関する文書・通知・Web掲載物・社内資料を作成する際には必ず本ガイドラインを遵守してください。

WESTERは単なる会員サービスではなく、JR西日本グループが掲げる「西日本エリアの人々の生活に寄り添い、移動・地域・暮らしをつなぐプラットフォーム」です。その理念をすべてのコミュニケーションに反映させることが、本マニュアルの目的です。

## 1. WESTERブランドアイデンティティ

### 1-1. ミッション（存在意義）

> **「西日本に暮らし、旅する人々の毎日をもっと豊かに、もっとつながりのあるものにする」**

WESTERは、鉄道を中心とした移動インフラと会員プログラムを融合させることにより、会員一人ひとりの日常生活・旅行・地域との関わりを豊かにすることを目指します。ポイント付与や特典提供にとどまらず、地域の魅力発見・移動体験の向上・コミュニティ形成を包括的に支援することがWESTERの使命です。

### 1-2. ビジョン（目指す姿）

> **「西日本エリア最大の生活密着型スマートプラットフォームとなり、移動・消費・地域活性のエコシステムを構築する」**

2030年までに達成すべき姿として、以下の3点を掲げます。

1. **会員基盤の拡大**: 西日本エリアに在住・在勤・通学する人々の過半数が何らかの形でWESTERサービスを利用している状態
2. **エンゲージメントの深化**: 単なるポイント収集から、WESTERアプリを起点とした日常行動（乗車・購買・観光・地域参加）のデジタル化
3. **地域共創の実現**: 沿線自治体・地域企業・観光事業者と連携し、地域課題解決に貢献するプラットフォームとしての確立

### 1-3. ブランドポジショニング

WESTERは以下の2軸で他社サービスと明確に差別化されます。

| 軸 | WESTERの立場 | 競合との差異 |
|---|---|---|
| 信頼性 | JR西日本グループのブランド背景を持つ、安心・安全な会員基盤 | 鉄道インフラの信頼性を直接的に受け継ぐ点で他の交通系・流通系ポイントと差別化 |
| 地域密着性 | 西日本エリアの沿線地域に根ざした地域課題解決型サービス | 全国型ポイントプログラムにはできない、地域固有の価値提供 |

**コアバリュー（ブランドを支える5つの価値）**:

1. **信頼 (Trust)**: JR西日本グループの安全・安心な運営基盤に根ざした、揺るぎない信頼性
2. **つながり (Connection)**: 人と人、人と地域、地域と地域をつなぐ架け橋としての役割
3. **発見 (Discovery)**: 日常の移動の中に新しい価値や体験を見つける喜びの提供
4. **誠実さ (Integrity)**: 会員・パートナーに対して誠実で透明性の高いサービス運営
5. **地域愛 (Regional Pride)**: 西日本の文化・自然・人々への深い敬意と愛情

### 1-4. ブランドパーソナリティ

WESTERをひとりの人物として表現するとすれば、以下のような人物像です。

> **「誠実で物知り、明るく温かい西日本の案内人」**

- 年齢感：30代中盤〜40代前半（落ち着きと活力の両立）
- 話し方：丁寧で分かりやすい。専門用語を使わずに複雑な情報を伝えられる
- 雰囲気：親しみやすいが軽すぎない。笑顔で対応するが、必要な場面では毅然とした態度も持つ
- 価値観：地元愛が強く、西日本の魅力を自然体で語れる

## 2. トーン＆マナー

### 2-1. 3つのキーワード

WESTERのすべてのコミュニケーションは、以下の3つのキーワードを基軸にトーンを設定します。

#### キーワード1：「正式 (Formal)」

WESTERはJR西日本グループの公式サービスであり、すべての対外コミュニケーションには組織としての正式さが求められます。これは「堅苦しさ」ではなく、「責任ある言葉遣い」を意味します。

**具体的な実践例**:
- 曖昧な表現を避け、事実に基づいた明確な情報提供を行う
- 「〜かもしれません」「〜だと思います」などの不確かな表現は用いない
- 日付・金額・ポイント数などの数値情報は正確に記載する
- 誤りが生じた場合は、ごまかさず速やかに訂正し謝罪する

**Good例（正式さを保った表現）**:
> 「2026年4月1日（水）より、WESTERポイントの有効期限ルールが変更となります。詳細は本メール下部の「変更内容」をご確認ください。」

**Bad例（曖昧・非公式な表現）**:
> 「近いうちにポイントのルールが変わる予定なので、ちょっと確認しておいてください。」

#### キーワード2：「信頼 (Trust)」

会員・パートナー・社会からの信頼を維持・向上させるために、誠実で一貫性のあるコミュニケーションを実践します。「信頼」は一度の文書で得られるものではなく、すべての接点での積み重ねによって形成されます。

**具体的な実践例**:
- 会員データの取り扱いに関する説明は丁寧かつ明確に行う
- 特典・ポイントの条件は漏れなく記載し、後から「実は条件があった」とならないようにする
- ネガティブな情報（サービス停止・制度変更・障害発生）も、ポジティブな情報と同様に迅速・丁寧に伝える
- 約束したことは必ず守り、変更が生じる場合は事前に連絡する

**Good例（信頼感のある表現）**:
> 「ご利用のポイントサービスにシステム障害が発生しており、現在ポイント反映が遅延しております。ご不便をおかけし、誠に申し訳ございません。復旧次第、順次反映を進めてまいります。進捗はWESTER公式サイトにてご確認いただけます。」

**Bad例（信頼感を損なう表現）**:
> 「ポイントが遅れているのはシステムのせいです。しばらく待ってください。」

#### キーワード3：「温かみ (Warmth)」

WESTERは西日本の地域と人々を愛する存在として、冷たいシステムのような印象を与えないコミュニケーションを目指します。「温かみ」とは過剰な感情表現ではなく、「人を大切にしている」という姿勢が言葉に滲み出ることです。

**具体的な実践例**:
- 会員を「ユーザー」ではなく「お客さま」と呼ぶ
- 特典やキャンペーン案内には、会員の体験・気持ちを想像した表現を使う
- 問い合わせ対応では、機械的な回答ではなく相手の状況に寄り添った言葉を選ぶ
- 地域の文化・風景・食などへの言及を通じて、西日本への愛着を伝える

**Good例（温かみのある表現）**:
> 「今年の春も、WESTERと一緒に西日本の桜を楽しみませんか。特別な春の旅をサポートする限定キャンペーンをご用意しました。」

**Bad例（冷たい・機械的な表現）**:
> 「春季キャンペーンを実施します。条件を満たした会員にポイントを付与します。」

## 5. 文章フォーマット標準

### 5-1. 見出しの使い方

**対外文書（メール・Web・通知）**:
- 大見出し：文書全体のタイトル。20字以内が理想
- 中見出し：セクションの区切り。10〜15字程度
- 小見出し：詳細項目の区切り。文章の流れを分かりやすくする
- 見出しには「。」を付けない
- 見出しの後には必ず改行を入れる

**社内文書**:
- 階層は「1. > 1-1. > (a)」の形式を推奨
- 見出し番号は必ず付ける
- 大見出しは太字にする

### 5-2. 箇条書きのルール

- 箇条書きの各項目は「・」（中点）を使用する
- 全角の「・」を使用し、半角の「·」は使用しない
- 項目末には原則として「。」を付けない（体言止め推奨）
- 各項目の長さを揃えるよう意識する（過度な長短の差は読みにくい）
- 5項目を超える場合は、グループ分け（小見出し）を検討する
- 番号付き箇条書きは、順序に意味がある場合（手順・優先順位等）のみ使用する

**Good例**:
```
WESTERポイントの主な特典内容：
・新幹線・在来線のチケット交換
・パートナー企業でのポイント利用
・WESTERアプリ限定デジタルクーポンへの交換
```

**Bad例**:
```
WESTERポイントの特典内容です：
- まず新幹線や在来線のチケットに交換できます。
- また、パートナー企業でも使えます。
- さらにWESTERアプリ限定のクーポンへの交換も可能です。
```

### 5-3. 数字・金額・日付の表記

| 種別 | 正式表記 | 禁止表記 | 例 |
|---|---|---|---|
| 日付 | YYYY年M月D日（曜日） | 26年4月1日、4/1 | 2026年4月1日（水） |
| 時刻 | H時MM分 | 14:00、PM2時 | 14時00分 |
| 金額 | 金額の後に「円（税込）」または「円（税抜）」を明記 | ¥1,000、1000円 | 1,000円（税込）|
| ポイント数 | 数字+「ポイント」 | 1,000P、1000pt | 1,000ポイント |
| パーセント | 数字+「%」（対外）/ 数字+「パーセント」（文章中） | ％（全角）、percent | 10%増加 / 10パーセント増加 |
| 順位・番号 | 算用数字 | 第一位、一番 | 第1位、1番 |
| 個数・人数 | 算用数字+単位 | 一名様、三個 | 1名さま、3個 |

**数字の桁区切り**:
- 4桁以上の数字にはカンマ区切り（1,000 / 10,000）
- 年号はカンマなし（2026年）

### 5-4. 敬語レベルの設定

WESTERのコミュニケーションでは、以下の4段階を場面に応じて使い分けます。

| レベル | 場面 | 特徴 | 例 |
|---|---|---|---|
| レベル4（最高敬語） | 重大なお詫び・経営層向け対外文書 | 尊敬語・謙譲語・丁寧語をすべて組み合わせる | 「この度は多大なるご迷惑をおかけし、誠に申し訳ございません」 |
| レベル3（標準丁寧語） | 一般的な会員向けメール・Web掲載 | 丁寧語+謙譲語。読みやすさとフォーマル感の両立 | 「〜いたします」「〜いただけます」「〜ございます」 |
| レベル2（親しみ敬語） | プッシュ通知・キャンペーン告知 | 丁寧語中心。やや親しみやすいトーン | 「〜できます」「ぜひ〜ください」「お得な〜」 |
| レベル1（平易な文体） | 社内チャット・内部メモ | 敬語は最低限。事実を簡潔に伝える | 「〜してください」「〜を確認します」 |

**敬語使用時の注意点**:
- 二重敬語（「おっしゃられる」「いただけられる」）は使用しない
- 「〜させていただきます」は乱用しない。「いたします」で代用できる場合は代用する
- 「ご〜いたします」「お〜します」の使い分けを正確に行う

## 6. チャネル別トーン調整

### 6-1. メール（会員向けメルマガ・通知メール）

**基本方針**: 正確な情報を丁寧かつ読みやすい形式で提供する。会員が行動を起こしやすい構成を意識する。

**フォーマット規則**:
- 件名は30字以内。重要キーワードを冒頭に置く
- 本文冒頭は「いつもWESTERをご利用いただき、誠にありがとうございます。」から始める
- 重要情報は冒頭300字以内に収める
- CTAボタン（リンク）は明確なアクション語（「詳細を確認する」「今すぐ登録する」）
- 末尾には問い合わせ先・配信停止リンクを必ず記載

**サンプル構成**:
```
件名：【WESTER】春のポイント2倍キャンペーン開始のお知らせ

いつもWESTERをご利用いただき、誠にありがとうございます。

■ 詳細・参加方法
[詳細はこちら]（リンク）

ご不明な点は、WESTERお客さまセンター（XXXX-XXXX-XXXX）までお問い合わせください。

─────────────────────────

─────────────────────────
```

### 6-2. プッシュ通知

**基本方針**: 会員の行動を促す短文メッセージ。スマートフォンの通知として表示されるため、簡潔・明確・価値が一目で伝わることが重要。

**フォーマット規則**:
- タイトル：15字以内
- 本文：50字以内
- 冒頭に【WESTER】を付ける
- 絵文字は使用しない（ブランドトーンとの不一致）
- 数字・期限・金額など具体的な情報を1つ盛り込む

**Good例**:
```
タイトル：【WESTER】期間限定！ポイント2倍
本文：4月中のご乗車でWESTERポイントが2倍になります。今すぐ確認を。
```

**Bad例**:
```
タイトル：お得情報✨
本文：春のキャンペーンやってます！ぜひアプリをチェックしてみてください😊
```

### 6-3. Web（公式サイト・アプリ内コンテンツ）

**基本方針**: 検索・閲覧目的のユーザーが必要な情報をすぐに見つけられる構成。視覚的な整理（見出し・箇条書き・表）を積極的に活用する。

**フォーマット規則**:
- ページタイトルはH1タグ相当。30字以内・キーワードを含む
- 本文はF字読みを意識した構成（重要情報を左上・上部に）
- FAQ形式では「Q.」「A.」のプレフィックスを使用
- リンクテキストは「こちら」ではなく行先が分かる文言（「WESTERポイント利用規約はこちら」→「WESTERポイント利用規約を確認する」）
- 更新日を必ずページ末尾に記載

### 6-4. 社内文書（報告書・企画書・議事録）

**基本方針**: 事実・根拠・結論・アクションが明確に伝わることを最優先。読み手の時間を尊重した簡潔な表現を使う。

**フォーマット規則**:
- 表題に日付・文書番号・作成者を記載
- 結論・サマリーを冒頭に1〜3行で記載（エグゼクティブサマリー形式）
- 数値・データは必ず出典を明記
- アクションアイテムは「担当：〇〇、期日：〇月〇日」の形式で明示
- 「です・ます」調と「だ・である」調を混在させない（社内文書は「だ・である」調を推奨）

## 7. WESTERの文脈理解

### 7-1. 鉄道×会員プログラムという複合性

WESTERは単なるポイントプログラムではなく、JR西日本の鉄道インフラと深く結びついています。この複合性を理解せずにコミュニケーションを作成すると、本来のWESTERの価値を伝えられません。

**鉄道文脈での重要概念**:
- **乗車体験との連動**: WESTERポイントはJR西日本の乗車から貯まる。乗車体験の向上とポイントは不可分
- **駅の役割**: 駅は単なる乗降地点ではなく、地域コミュニティのハブ。WESTERの施策は「駅を起点とした地域活性」を意識する
- **ネットワーク価値**: JR西日本の路線網が広がるほど、WESTERの価値も広がる。路線拡大・新幹線開通等のニュースはWESTERにとっても重要なコンテキスト

**会員プログラム文脈での重要概念**:
- **会員ステージ制度**: WESTERには利用実績に応じた会員ステージ（グレード）が存在する。コミュニケーションはステージによって差別化することが望ましい
- **ポイント経済圏**: WESTERポイントはJR西日本グループ内外のパートナー企業でも利用できる。「ポイントで生活が豊かになる」という視点
- **行動変容**: 単なるポイント付与ではなく、会員の行動（乗車頻度・観光・消費）を変容させることがWESTERの真の目的

### 7-2. 地域まちづくりとの接続

WESTERは「移動インフラ×地域まちづくり」の文脈で語られることが増えています。単なるマーケティング施策ではなく、社会的な意義を持つプラットフォームとして位置づけることが重要です。

**具体的な接続ポイント**:
- 沿線自治体との連携キャンペーン（観光促進・移住促進等）
- 地域商店街・中小企業とのポイント連携
- 地域の祭り・文化イベントとのスタンプラリー連動
- 過疎地域の公共交通維持への貢献（乗車促進施策）

**コミュニケーション上の注意点**:
- 地域施策の告知では、その地域固有の文化・魅力を必ず盛り込む
- 「効率化」「最適化」などの無機質な表現よりも、「つながり」「発見」「地域愛」を前面に出す
- 沿線地域の表現では、地名の正確な表記と読み方を確認する（例：姫路市→「ひめじし」、福知山市→「ふくちやまし」）

### 7-3. デジタルと現実の融合

WESTERアプリ・デジタル会員証・QRコード乗車などのデジタル技術と、実際の駅・電車・地域といったリアルな体験が融合しているのがWESTERの特徴です。

**コミュニケーションへの示唆**:
- デジタル施策の告知でも「実際の体験」への橋渡し感を持たせる
- 「アプリを開いて〜」という操作案内と「実際に電車に乗って〜」という体験案内をセットで提供する
- 高齢者・デジタル不慣れ層への配慮として、デジタル以外の手段も案内に含める（窓口での手続き等）

## 8. NG例と改善例

実際のコミュニケーション事例を通じて、NGの理由と改善方法を学んでください。

### ケース1：キャンペーン告知メール（件名）

| | 内容 |
|---|---|
| NG例 | 「【緊急告知】超お得！！ウエスターポイント5倍キャンペーン開始！」 |
| NG理由 | ①「緊急」は誤解を招く（緊急ではないキャンペーンに使用するのは不誠実）②「超お得！！」は感嘆符連続・「超」使用で禁止表現③「ウエスター」は正式表記違反 |
| 改善例 | 「【WESTER】期間限定・WESTERポイント5倍キャンペーン開始のお知らせ」 |

### ケース2：ポイント有効期限の通知

| | 内容 |
|---|---|
| NG例 | 「ポイントが消えちゃいます！早めに使ってね！」 |
| NG理由 | ①「消えちゃいます」は口語的・不正確（正式には「失効」）②「使ってね」は命令的かつ軽薄 |
| 改善例 | 「保有WESTERポイントの有効期限が2026年3月31日（火）に迫っております。失効前にぜひご利用ください。」 |

### ケース3：システム障害発生時のお知らせ

| | 内容 |
|---|---|
| NG例 | 「システムに不具合が生じているかもしれないため、ポイントの反映が遅れる場合があります。」 |
| NG理由 | ①「かもしれない」「場合があります」と二重の曖昧表現で責任が不明確②障害発生の事実を明言せず、不誠実な印象 |
| 改善例 | 「現在、WESTERポイントシステムにおいて障害が発生しており、ポイントの反映に遅延が生じております。ご不便をおかけし、誠に申し訳ございません。復旧の見込みは〇月〇日〇時を予定しております。」 |

### ケース4：新機能のアプリ内案内

| | 内容 |
|---|---|
| NG例 | 「新機能が追加されました！簡単に使えるので、今すぐゲットしてください！」 |
| NG理由 | ①「ゲット」は禁止表現②「簡単」は機能の複雑さによっては誤解を招く③「！」が多く軽薄な印象 |
| 改善例 | 「WESTERアプリに新機能「〇〇」が追加されました。3ステップで簡単にご設定いただけます。詳しい使い方は[ヘルプページ]をご覧ください。」 |

### ケース5：地域キャンペーンの告知コピー

| | 内容 |
|---|---|
| NG例 | 「近畿・中国・四国エリアの一部店舗でポイントが使えます。」 |
| NG理由 | ①「近畿・中国・四国エリア」は正式表記では「西日本エリア」を使用②「一部店舗」では対象が不明確で会員が行動できない |

### ケース6：問い合わせ対応メール

| | 内容 |
|---|---|
| NG例 | 「お問い合わせの件ですが、システム側の問題なのでこちらではどうにもできません。」 |
| NG理由 | ①責任回避の姿勢が明確で、会員に対して冷たい印象②「こちらではどうにもできません」は解決への誠意がない |
