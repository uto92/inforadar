# クレーム対応マニュアル
## WESTER会員クレーム対応 実務規範（新人研修版）

**文書種別**: スキルマニュアル（新入担当者研修用）
**対象**: クレーム対応・エスカレーション・再発防止に関わるすべてのエージェント・担当者
**最終更新**: 2026年3月
**管理責任**: WESTERカスタマーサクセスチームリード

---

## はじめに

本マニュアルは、WESTER会員から寄せられるクレーム・苦情・不満・トラブル報告への対応を標準化するために作成されました。

クレームは「嫌なもの」ではありません。クレームを言ってくれる会員は、まだWESTERに期待しています。黙って退会した会員より、はるかに価値あるフィードバックをくれています。一つのクレームを適切に対応することで、その会員は生涯のロイヤルカスタマーになる可能性があります。一方、一つのクレームへの不適切な対応が、SNSでの拡散・メディア報道・集団訴訟の端緒になることもあります。

このマニュアルに従い、全てのクレームを「WESTERの改善機会」として向き合ってください。

## 1. WESTER会員クレーム対応の基本哲学

### 1-1. JR西日本のサービス理念とクレーム対応

JR西日本は「安全・安心・快適なご旅行・ご利用を提供する」という使命のもと、約1,300万人のWESTER会員へのサービスを提供しています。鉄道という公共インフラを担う事業者として、個別の会員対応においても「公正・誠実・責任」という姿勢を貫くことが求められます。

**クレーム対応における3つの原則：**

1. **誠実であること：** 事実と異なることを言わない。わからないことは「わからない」と言う。確認が必要なことは「確認してご連絡します」と約束し、必ず守る。
2. **迅速であること：** 会員は返答を待っている。遅い対応は「無視された」という感情を生み、クレームの重大度を引き上げる。
3. **解決を目指すこと：** 謝罪で終わらせない。「今後どうするか（再発防止策）」をセットで伝える。

### 1-2. クレーム対応者の心得

クレーム対応は精神的に負荷のかかる仕事です。担当者が消耗しないための心得を理解してください。

- **会員の怒りはあなた個人への攻撃ではない。** 会員はサービス・システム・規約に怒っています。あなた個人の人格を否定しているわけではありません。
- **完璧な対応は存在しない。** どんなに丁寧に対応しても、全員が満足する結果は出せません。「誠実に・適切に対応した」という事実が重要です。
- **一人で抱え込まない。** 重大なクレームは必ずエスカレーションします。「自分で解決しなければ」という義務感が判断を曇らせます。

## 2. クレーム対応の5ステップ

### ステップ1：受付（Accept）

**目的：** 会員の状況を正確に把握し、クレーム対応を開始する

**実施事項：**

1. 会員の話を**最後まで聞く**（途中で遮らない。会員が言いたいことを全部言い終えるまで待つ）
2. 話を聞きながら以下の情報を記録する：
   - 会員番号（会員ランク）
   - クレームの内容（何が起きたか）
   - いつ起きたか（発生日時）
   - 何を求めているか（返金・謝罪・改善・説明等）
   - 会員の感情温度（落ち着いている / 怒っている / 非常に激昂している）
3. 「ご連絡いただきありがとうございます」「ご不便をおかけして大変申し訳ございません」という受付の言葉を伝える
4. 「内容を確認して改めてご連絡します」と伝え、対応期限を約束する（例：「3営業日以内にご連絡いたします」）

**注意：**
- まだ事実確認ができていない段階で「私どものミスです」「すぐに対応します」等の断定的な謝罪・約束をしない
- 会員が怒っている場合でも、感情的に反応しない

---

### ステップ2：分類（Classify）

**目的：** クレームをカテゴリ・重要度・緊急度で分類し、対応の優先順位を決定する

**分類はcomplaint_classifierに依頼する。** 以下は人間担当者が分類を行う場合の基準。

**カテゴリ分類の基準：**

| カテゴリ | 内容 | 代表例 |
|---------|------|--------|
| A：システム・技術障害 | アプリ・Webシステムの不具合 | ポイントが反映されない・アプリが落ちる |
| B：ポイント・特典トラブル | ポイントの付与・失効・交換の問題 | ポイントが消えた・特典が使えない |
| C：キャンペーン・企画トラブル | キャンペーン告知と実態の乖離 | 告知と条件が違う・スタンプが押されない |
| D：接客・サービス品質 | 人的サービス接点でのクレーム | コールセンターの対応が不親切 |
| E：個人情報・セキュリティ | 個人情報・不正アクセス疑念 | 身に覚えのないポイント使用・情報漏洩疑念 |
| F：その他・複合 | 上記に分類できないもの | サービス全体への包括的不満 |

**重要度の判定（5段階）：**

| 重要度 | 定義 | 対応期限 |
|-------|------|---------|
| 1（低） | 単一会員・実害なし・誤解ベース | 48時間以内 |
| 2（やや低） | 単一会員・軽微な実害 | 当日中 |
| 3（中） | 実害あり・SNSリスクあり・1,000〜10,000円相当 | 4時間以内に初期回答 |
| 4（高） | 多数会員・法的リスク・報道リスク | 1時間以内に初期回答・上長即時報告 |
| 5（最重大） | JR西日本ブランドへの直接的脅威 | 30分以内・CSチームリード単独対応禁止 |

---

### ステップ3：対応（Act）

**目的：** 分類結果に基づき、適切な対応を実施する

**重要度別の標準対応：**

**重要度1・2（低・やや低）：標準対応フロー**

1. 事実確認（システムログ・規約・過去のクレーム履歴の照合）
2. 回答文の作成（response_drafter を使用）
3. 会員への回答送付
4. クレーム対応記録への入力
5. 再発防止の観点から同種クレームを積み上げる（3件以上で recurrence_prevention に連携）

**重要度3（中）：優先対応フロー**

1. 受付から4時間以内に「確認中」の一次回答を送付する
2. 事実確認を最優先で実施する
3. escalation_judge に自己処理可否を確認する
4. 自己処理可能と判断された場合、24時間以内に解決策を含む回答を送付する
5. recurrence_prevention に連携し、再発防止策を立案する

**重要度4・5（高・最重大）：緊急対応フロー**

1. 即時（30分以内）に上長へ口頭で第一報を伝える
2. escalation_judge を起動し、エスカレーション先・報告書ドラフトを作成する
3. 上長の指示に従って対応方針を確定する
4. 1時間以内に「確認中・調査中」の一次回答を会員に送付する（上長承認後）
5. 06_executive_report に連携し、経営層向けの報告資料を作成する

---

### ステップ4：解決（Resolve）

**目的：** 会員が納得できる解決策を提示・実行する

**解決策の設計原則：**

1. **事実に基づく解決：** 規約・システムログ・証拠に基づいて判断する。「なんとなく不満そうだから」という感情論での解決策提示は禁止。
2. **一貫性のある解決：** 同種のクレームに対して、異なる解決策を提示しない（不公平感を生む）。
3. **過剰補償の禁止：** 「クレームが怖いから多めに補償する」という発想は禁止。規約に基づかない過剰補償は前例となり、今後すべての同種クレームへの対応水準を引き上げる。
4. **解決策の明示：** 「今後気をつけます」で終わらせない。「何を・いつまでに・どう改善するか」を具体的に伝える。

**解決策の種別と判断基準：**

| 解決策 | 適用条件 | 注意点 |
|-------|---------|-------|
| 謝罪のみ | 会員の誤解に基づくクレーム・実害なし | 誤解を丁寧に解きながら謝罪 |
| ポイント補填 | システム障害等の実証済みの実害 | 規約に基づく補填。過剰補填しない |
| 特典の提供 | 会員の信頼回復が必要な場合 | 上長承認が必要な場合あり |
| 規約・告知の改善 | 規約・告知不備が原因の場合 | 改善後に会員に報告する |
| 返金・補償 | 金銭的損失が実証された場合 | 上長承認必須・法務確認が必要な場合あり |

---

### ステップ5：再発防止（Prevent）

**目的：** 同種のクレームが二度と発生しないための改善を行う

**再発防止のプロセス：**

1. クレーム対応完了後、recurrence_prevention に連携する
2. 根本原因分析（5Why分析）を実施する
3. 改善策（プロセス・規約・告知・システム・組織の5層）を設計する
4. 優先度Aの改善策（今週中・CSチームリード単独実行可能なもの）から着手する
5. 改善の実施後、効果をKPIで測定する

## 3. 重要度別対応標準（重要度1〜5の具体的対応手順）

### 重要度1：低（Low）

**定義：** 単一会員の軽微な不便。実害なし。誤解ベースの可能性が高い。

**対応手順：**
1. 受付から48時間以内に回答する
2. 誤解を生んでいた場合は、規約・ルールを丁寧に説明する
3. 「今後わかりやすくなるよう改善を検討します」という一文を添える
4. クレーム内容を記録し、同種クレームが3件以上蓄積したらrecurrence_preventionに連携する

**回答のトーン：** 温かく・丁寧に。「あなたの疑問は理解できる」という共感を表しながら、事実を説明する。

---

### 重要度2：やや低（Moderate-Low）

**定義：** 単一会員に明確な不満。対応次第では関係悪化の可能性。軽微な実害あり。

**対応手順：**
1. 当日中に回答する
2. 会員の感情に対して先に共感を示す（「ご不満をお感じになったこと、ご理解できます」）
3. 事実確認を行い、実害がある場合は規約に基づく補填を行う
4. 「会員様のご意見を改善に活かします」という具体的なコメントを添える
5. クレーム対応記録に登録する

---

### 重要度3：中（Moderate）

**定義：** 実害あり。SNSリスクあり。1,000〜10,000円相当の損失。感情的高揚あり。

**対応手順：**
1. 受付から4時間以内に一次回答（確認中である旨）を送付する
2. escalation_judge に自己処理可否を確認する
3. 事実確認を最優先で実施する（当日中）
4. 24時間以内に解決策を含む最終回答を送付する
5. 会員の感情的高揚度が高い場合は、回答前に上長に確認を取る
6. 「弁護士」「消費者センター」「SNS」等のキーワードが出た場合は escalation_judge へ再確認
7. 案件完了後、recurrence_prevention に連携する

---

### 重要度4：高（High）

**定義：** 多数会員に影響。法的リスク・報道リスクが具体的に存在。金銭的損失が大きい。

**対応手順：**
1. **30分以内に上長へ口頭で第一報を伝える。**
2. escalation_judge を起動し、エスカレーション先と報告書ドラフトを取得する
3. 上長の指示に基づき対応方針を確定する（CSチームリード単独での対応方針決定は禁止）
4. 1時間以内に会員への一次回答（「現在調査中。◯日以内に詳細をご連絡します」）を上長承認後に送付する
5. 影響を受ける全会員への告知が必要な場合、告知文案を作成・上長承認を取得する
6. 06_executive_report に連携し、経営層向けレポートを作成する
7. 外部（メディア・消費者センター等）への対応が必要な場合は、広報部門と連携する

---

### 重要度5：最重大（Critical）

**定義：** JR西日本ブランドへの直接的脅威。集団訴訟・メディア報道・個人情報漏洩等。

**対応手順：**
1. **即時（5分以内）に上長へ電話で第一報を伝える。** 上長が不在の場合はその上位者へ。
2. **CSチームリードが単独で対応方針を決定することは絶対禁止。**
3. 上長・法務部門・広報部門・IT部門（セキュリティ関連の場合）を召集する
4. 30分以内に関係者全員への緊急招集を行う
5. escalation_judge・06_executive_report に即時連携する
6. 会員への対応は上長・法務の承認後に行う
7. 外部（メディア・行政機関等）への対応は必ず広報部門が主導する

## 4. 回答文章の書き方

### 4-1. クレーム回答の基本構成（5部構成）

1. **共感・受け止め（Opening Empathy）：** 会員の不満・不便を受け止める。謝罪はここで行う。
2. **事実の説明（Fact Explanation）：** 何が起きたか・なぜそうなったかを客観的に説明する。
3. **解決策の提示（Resolution）：** 具体的な解決策を提示する。
4. **再発防止のコメント（Prevention Statement）：** 「今後どう改善するか」の一言。
5. **締め・感謝（Closing Appreciation）：** 連絡への感謝と、今後の利用継続への期待。

## 5. エスカレーション判断基準と手順

### 5-1. エスカレーションが必要な判断基準

以下のいずれか一つでも該当する場合は、**即時エスカレーション**とする：

| 条件 | 具体例 |
|------|--------|
| 重要度4または5 | 大規模障害・集団クレーム・法的措置の予告 |
| 法的措置の予告 | 「弁護士を通じて」「法的措置を取ります」 |
| SNS・メディアへの拡散予告または実際の拡散 | 「Twitterに書きます」・既にバズっている |
| 個人情報漏洩・不正アクセスの具体的疑念 | 「身に覚えのないログイン」「情報を盗まれた」 |
| 複数チャネルからの同時多発クレーム | 1時間以内に5件以上の同種クレーム |
| CSチームリードの権限範囲外の意思決定が必要 | 大額の補填・規約の特別解釈 |

### 5-2. エスカレーションの手順

1. **第一報は口頭（電話）で：** 緊急エスカレーションは必ずまず口頭で伝える。メールだけの報告は見逃すリスクがある。
2. **第二報は書面で：** escalation_judge が作成した上長報告書ドラフトを使い、30分以内にメールで報告書を送付する。
3. **一次回答は上長承認後に：** 重要度4以上の場合、会員への回答は上長の承認を取得してから送付する。
4. **対応の記録：** エスカレーションの経緯・上長の判断・対応内容をすべて時系列で記録する。

### 5-3. 上長報告のポイント

上長への報告は「PREP形式」で行う：
- **Point（結論）：** 何が起きているか・どれくらい深刻か（重要度）を最初に伝える
- **Reason（根拠）：** なぜその重要度と判断するか
- **Example（具体例）：** クレームの内容・会員の言葉（キーワード）
- **Point（結論＋推奨）：** CSチームとしての推奨対応方針

## 6. SNS炎上リスクへの対応

### 6-1. SNS炎上リスクの評価

以下の条件が重なるほど炎上リスクが高い：

| リスク因子 | 低リスク | 中リスク | 高リスク |
|----------|--------|--------|--------|
| 問題の影響範囲 | 個人のみ | 数十名 | 数百名以上 |
| 会員の感情強度 | 落ち着いている | 不満が明確 | 怒り・不信感が強い |
| 投稿の可能性 | なし | SNSに書くかも | 「書く」と明言 |
| 既存の投稿 | なし | 数件 | バズっている |
| 問題の公益性 | 個人の事情 | WESTER全体に関わる | 鉄道・公共サービスへの批判 |

### 6-2. SNS炎上の初動対応

**段階1：炎上の予兆（投稿はあるが拡散は小規模）**

1. escalation_judge に報告（重要度3〜4として処理）
2. 上長への情報共有（口頭または今日中のメール）
3. 投稿内容の事実関係を確認する
4. 投稿の会員本人への個別連絡を検討する（誠意ある対応が炎上を防ぐことが多い）
5. SNSモニタリングを強化する（広報部門に連絡）

**段階2：炎上（拡散が進んでいる）**

1. **即時エスカレーション（重要度5）：** 上長・広報部門に電話で第一報
2. 公式発表の要否を上長・広報部門と協議する
3. 公式発表を行う場合、内容・タイミング・チャネルは広報部門が主導する
4. CS部門からの個別対応は「上長・広報承認済みの方針」に基づいてのみ行う

### 6-3. 発信者への対応原則

- SNSに投稿している会員が特定できる場合、個別に丁寧なDM・コンタクトを取ることが有効な場合がある
- ただし、「削除してほしい」という要求はしない（かえって炎上する）
- 「誠実に問題解決に取り組んでいる」という姿勢を示すことが目的
- SNS上での公開論争はしない

## 7. 個人情報・セキュリティ関連クレームの特別手順

### 7-1. 個人情報・セキュリティ関連クレームの分類

| 種別 | 具体例 | 初期対応の優先度 |
|------|--------|--------------|
| 不正ログイン疑念 | 知らない端末からのログイン記録がある | 最優先（即時対応） |
| ポイントの不正使用 | 身に覚えのないポイント使用が記録されている | 最優先（即時対応） |
| フィッシング被害疑念 | WESTERを名乗る怪しいメールが来た | 優先（当日中） |
| 個人情報漏洩疑念 | WESTERから情報が漏れたのではないか | 重要（4時間以内） |
| 退会後のメール継続 | 退会したのにメールが届く | 通常（48時間以内） |

### 7-2. 不正ログイン・不正使用発生時の対応手順

1. **会員への即時対応（30分以内）：**
   - パスワード変更の案内
   - 不正使用が疑われるポイントの一時凍結（システム対応）
   - IT部門・セキュリティ部門への即時連絡

2. **調査の実施：**
   - ログイン履歴・ポイント使用履歴の確認
   - 不正アクセスの場合、影響範囲（他会員への波及可能性）の確認
   - セキュリティ部門と連携した原因究明

3. **エスカレーション（重要度4〜5）：**
   - 上長への即時報告
   - 個人情報保護委員会への報告義務の有無を法務部門に確認
   - 影響範囲が大きい場合は全体告知を検討

4. **会員への最終回答：**
   - 調査結果の説明（確認できた事実のみ。不明点は「不明」と明示）
   - 不正使用が確認された場合の補填対応（規程に基づく）
   - 再発防止策の説明

### 7-3. 個人情報保護法上の対応義務の確認

個人情報の漏洩・滅失・毀損が発生した（または疑われる）場合：

- 個人情報保護法第26条に基づき、個人情報保護委員会への報告義務が生じる可能性がある
- この判断は法務部門が行う。CSチームリードが単独で判断しない
- 法務部門への連絡は「セキュリティ関連クレームが発生した」時点で即時行う

## 8. 再発防止分析フレームワーク

### 8-1. 5Why分析（なぜなぜ分析）の実施手順

**5Why分析の基本ルール：**

1. 問い方は「なぜ（出来事）が起きたか」。「なぜ（人）は〜しなかったか」という人への問いは禁止
2. 最低5層まで掘り下げる。「担当者の確認漏れ」「周知不足」で止まるのは禁止
3. 一つの「なぜ」に複数の原因がある場合は全て追いかける
4. 最終的な根本原因に対して「この問題を解消すれば現象は起きなくなるか？」を検証する

**5Why分析の実例：**

```
現象：「キャンペーンのポイントが付与されていない」というクレームが10件発生した

なぜ1：キャンペーン参加者にポイントが付与されなかった
  → なぜ2：ポイント付与バッチ処理がエラーで停止していた
      → なぜ3：バッチ処理の対象テーブルに想定外のNULL値が含まれていた
          → なぜ4：キャンペーン参加時の入力値のバリデーションが不十分だった
              → なぜ5：要件定義段階でエラーハンドリングの要件を定義していなかった
                  → 根本原因：システム開発の要件定義プロセスにエラーハンドリング仕様の
                              定義が義務化されていない（プロセス層の問題）

改善策：全システム開発案件の要件定義書に「異常系処理の定義」を必須項目として追加する
```

### 8-2. 改善策の5層分類

| 層 | 改善対象 | 具体的な改善例 |
|----|---------|-------------|
| プロセス層 | 業務フロー・チェック手順 | 告知確認フローへの法務確認工程の追加 |
| 規約層 | 会員規約・利用規約 | 失効ルールの記述をより明確にする改定 |
| 告知層 | 告知文・FAQ・ヘルプ | キャンペーン告知にQ&Aを追加する |
| システム層 | アプリ・Webシステム | 失効前の自動メール通知機能の実装 |
| 組織層 | 研修・マニュアル・体制 | 窓口担当者向けのキャンペーンブリーフ実施 |

## 9. 心理的安全のための担当者ケア

### 9-1. クレーム対応の精神的負担について

クレーム対応は、程度の差はあれ必ず精神的な消耗を伴います。特に一人体制のCSチームリードは、「自分で対応しなければ」というプレッシャーを感じやすく、重大クレームへのエスカレーション躊躇や、慢性的なストレスの蓄積が起きやすい環境にあります。

以下の事実を認識してください：

**クレーム対応で消耗するのは自然なことである：** 怒った人に対応することは、人間として疲れる体験です。これは「弱さ」ではなく「人間らしさ」です。

**全員を満足させることは不可能である：** どんなに誠実に対応しても、全員が納得する結果を出すことはできません。「誠実に・適切に対応した」という事実が重要です。

**エスカレーションは逃げではない：** 重大クレームを上長にエスカレーションすることは、組織の機能を正しく使うことです。一人で抱え込んで問題を大きくすることの方が問題です。

### 9-2. セルフケアの具体的な方法

**クレーム対応後の気持ちの切り替え：**

- 対応が完了した後は、5分間「別の作業（事務・読書・散歩等）」に切り替える時間を意識的に設ける
- 感情的に消耗したクレームの後は、「自分が誠実に対応した」という事実を記録として残す
- 特に激しいクレームの後は、上長や信頼できる同僚に「今日こういうクレームがあった」と話すだけでも気持ちが軽くなる

**重大クレームが重なる時期の対処：**

- クレームが多発している時期は、優先度を明確にして「今日対応するもの」「今週対応するもの」を分類する
- 「全部今日中に解決しなければ」という思い込みを手放す。優先度の低いクレームは適切な期限を設けて処理する
- 自分一人での処理が限界を超えていると感じたら、上長に「サポートが必要な状況」と報告する

## 10. NG表現集・OK表現集（25ペア）

クレーム対応における表現は、同じ意味でも受け取り方が大きく異なります。以下のNG表現は使用禁止、OK表現を使ってください。

### 謝罪・受け止めに関する表現

| NG表現 | 問題点 | OK表現 |
|-------|-------|-------|
| 「それはご不満なんですね。」 | 共感が薄く、受け流している印象 | 「ご不便をおかけして誠に申し訳ございません。」 |
| 「ご意見として承りました。」 | 何もしないと受け取られる | 「ご意見を確認し、改善に取り組んでまいります。」 |
| 「貴重なご意見ありがとうございます。」（謝罪なしで) | 問題を矮小化している印象 | 先に謝罪し、その後「貴重なご連絡をいただきありがとうございます」 |
| 「申し訳ありませんが、規約上…」 | 謝罪の後に「でも」が続く構造で誠意がない | 「規約上の定めによりご期待に沿えない部分もございますが、…」 |
| 「こちらとしては問題ないと認識しております。」 | 会員の感情を否定している | 「お客様のお立場からは〇〇とお感じになるのは理解できます。一方で、〜」 |

### 事実説明に関する表現

| NG表現 | 問題点 | OK表現 |
|-------|-------|-------|
| 「仕様です。」 | 冷たく、問題を認めない印象 | 「現在の仕様ではそのような動作となっております。ご不便をおかけしております。」 |
| 「説明書に書いてあります。」 | 会員を責める印象 | 「ご説明が不十分でご迷惑をおかけいたしました。」 |
| 「それは不可能です。」 | 頭ごなしに否定する印象 | 「現状ではその対応が難しい状況ですが、〇〇という代替案がございます。」 |
| 「他のお客様は問題なく使えています。」 | 会員の問題を否定する印象 | 「多くの場合は正常に動作しておりますが、お客様の環境で発生している原因を確認いたします。」 |
| 「ポイントは失効しました。戻りません。」 | 事実だが冷たい表現 | 「ポイントの有効期限が過ぎてしまったため、誠に恐れ入りますが、現時点でのご返還が難しい状況です。」 |

### 解決策の提示に関する表現

| NG表現 | 問題点 | OK表現 |
|-------|-------|-------|
| 「今後は気をつけてください。」 | 会員を責める印象 | 「今後は告知方法の改善に取り組んでまいります。」 |
| 「今回は特別に対応します。」 | 不公平感・前例化のリスク | 「このたびの経緯を鑑み、〇〇ポイントをお付けいたします。」（「特別」は使わない） |
| 「難しいかもしれませんが、検討してみます。」 | やる気のなさを感じさせる | 「〇〇については、XX日までに確認してご連絡いたします。」 |
| 「上の者に確認します。」 | 責任の所在が不明確 | 「上長と協議の上、XX日までにご回答いたします。」 |
| 「できることとできないことがあります。」 | 何もしない言い訳に聞こえる | 「〇〇については対応可能ですが、△△については現状難しい状況です。」 |

### 時間・期限に関する表現

| NG表現 | 問題点 | OK表現 |
|-------|-------|-------|
| 「なるべく早く対応します。」 | 期限が不明確で信頼されない | 「XX月XX日（曜日）までにご連絡いたします。」 |
| 「少々お待ちください。」 | どれくらい待てばいいかわからない | 「確認に〇分頂戴できますでしょうか。」 |
| 「そのうち改善されると思います。」 | 確証のない約束 | 「改善の予定については現時点では確定した日程をお伝えできませんが、改善され次第ご案内いたします。」 |
| 「対応は順番になります。」 | 無視されている印象 | 「大変お時間をいただいており申し訳ございません。XX日までに必ずご連絡いたします。」 |

### クレームの深刻さへの対応に関する表現

| NG表現 | 問題点 | OK表現 |
|-------|-------|-------|
| 「落ち着いてください。」 | 会員の怒りを否定・抑制する | （何も言わず、会員が話し終えるまで聞く） |
| 「クレームは担当外です。」 | 会員を放置する最悪の表現 | 「担当部署に引き継ぎ、必ずご連絡させていただきます。」 |
| 「同様の問い合わせが多く…」 | 会員の問題を軽視している印象 | 個別の問題として真摯に対応する |
| 「SNSに書かれても困ります。」 | 会員の権利を否定・圧迫 | 絶対に言わない。SNS投稿への言及は反応しない |
| 「弁護士を使うのはやめてください。」 | 会員の権利を否定 | 絶対に言わない。法的措置を予告された場合は即時エスカレーション |
