# inforadar — JR西日本 主要駅 混雑ヒートマップ(推定)

京都観光客の人流ヒートマップ(Agoopデータ)風の時間帯アニメーションを、
**JR西日本の主要駅 約50駅**(京阪神・岡山・広島・山口・山陰・北陸)で再現したWeb可視化です。

ダークな地図の上に、朝5時〜深夜0時の駅周辺の混雑度を緑→黄→赤のヒートマップで
アニメーション表示します。

## 使い方

ビルド不要。ローカルでそのまま開けます。

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

(`index.html` をダブルクリックでも動きますが、ローカルサーバー経由を推奨)

GitHub Pages を有効にすればそのまま公開できます(Settings → Pages → ブランチを選択)。

### 操作

- **▶ / ⏸** — 時間帯アニメーションの再生・停止(5:00〜24:59 でループ)
- **スライダー** — 時刻を直接指定
- **×10/×20/×45/×90** — 再生速度(実時間1秒あたりの経過分数)
- **エリアボタン** — 京阪神 / 大阪 / 神戸 / 京都 / 岡山・広島 / 山陰 / 北陸 / 全域 にジャンプ
- **駅にマウスオーバー** — 駅名・乗車人員・その時刻の推定混雑度を表示

## データについて(重要)

これは**実測の人流データではなく、推定モデルによるイメージ可視化**です。

- **駅の規模**: JR西日本が公表している駅別の1日平均乗車人員(近年度)をもとにした概算値
  (`data/stations.js` に記載。値は丸めた概数です)
- **時間帯変動**: 駅を5タイプ(ターミナル / 通勤 / 観光 / 繁華街 / 地方中核)に分類し、
  タイプごとの典型的な時間帯カーブ(平日イメージ)を定義して混合
- **ヒートマップの広がり**: 駅ごとに設定した目安半径の中に、シード付き乱数で
  「人だまり」の点群を散らして描画(毎回同じ形になります)

実測データ(例: Agoopポイント型流動人口、モバイル空間統計、
[全国の人流オープンデータ](https://www.geospatial.jp/ckan/dataset/mlit-1km-fromto)等)が
手に入れば、`data/stations.js` の形式に合わせて差し替えることで実データ版にできます。

## 構成

```
index.html        アプリ本体(ビルド不要)
data/stations.js  駅データ(座標・乗車人員・タイプ)、時間帯プロファイル、エリア定義
lib/              MapLibre GL JS 4.7.1(同梱。外部CDN不要)
```

- 地図ライブラリ: [MapLibre GL JS](https://maplibre.org/)(リポジトリに同梱)
- ベースマップ: [CARTO Dark Matter](https://carto.com/basemaps/)(© OpenStreetMap contributors, © CARTO)

## カスタマイズ

- 駅の追加・修正: `data/stations.js` の `STATIONS` 配列に追記
- 時間帯カーブの調整: 同ファイルの `HOURLY_PROFILES`(5時台〜24時台、1時間刻み)
- 色・にじみ具合: `index.html` 内 `crowd-heat` レイヤーの `heatmap-color` / `heatmap-radius` / `heatmap-intensity`
