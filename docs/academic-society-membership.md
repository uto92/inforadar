# 学会・団体 所属方針メモ

会費・手続き期限は未確認のため「要確認」とし、確認後に埋める。

## 土木学会（退会）

やること:

- [ ] 退会届の様式と提出先を確認する（会員規程・事務局ページ）
- [ ] 退会の受付期限を確認する。年度単位で会費が発生する学会では、期限を過ぎると翌年度分の会費が発生するのが一般的なので、先に期限だけ押さえる
- [ ] 未納会費の有無を確認する（未納があると退会処理が進まない場合がある）
- [ ] 委員会・小委員会などの役職を持っていないか確認し、あれば引き継ぎ
- [ ] 継続中の投稿論文・発表申込みがないか確認（会員資格が条件になっていることがある）
- [ ] 退会届を提出し、受理の連絡を保存する

## 日本技術士会（保留）

判断を分ける論点:

- **資格そのものとの関係**: 技術士の資格保持と日本技術士会への入会は別。会を退会しても技術士の登録は失われない。ここを取り違えていないか最初に確認する。
- **CPD（継続研鑽）**: CPD実績の登録・証明を会のしくみに依存しているか。他手段で代替できるなら会に留まる理由は弱まる。
- **部会・支部の実利**: 直近1年で、部会・研究会・交流の場を実際に何回使ったか。使っていないなら費用対効果は低い。
- **対外的な位置づけ**: 業務・提案・登録要件で会員であることを求められる場面があるか。
- **費用**: 年会費と、上記で得ているものが釣り合うか。

決め方の目安: 上の「実際に何回使ったか」がゼロに近く、CPDを会に依存していないなら退会。どれか一つでも実務上必要なら継続。

- [ ] 直近1年の参加実績を数える
- [ ] CPD登録の依存有無を確認する
- [ ] 上記を踏まえて 継続／退会 を決め、この表を更新する
